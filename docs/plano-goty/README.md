Decisões da coordenação que se sobrepõem aos planos de área:
- Protagonista = Cris (roteiro); Íris é a voz. As mecânicas de escuta do game design ficam.
- P2P e backend fora da 1.0; Rádio dos Vivos vira atualização gratuita depois do lançamento.
- Fatia v0 até 10/jan/2027 (BIG Festival, 15/jan) e fatia completa (G1) até 28/fev/2027 (Tribeca, 4/mar).
- Tudo que o jogador vê ou ouve é de autoria humana ou procedural determinística; os textos-amostra do roteiro são prova de tom, não texto final.
